# Orvulix

Free online tools for JSON, PDF, images, text, and everyday tasks.

**Website:** https://orvulix-web.netlify.app/

## Stack

- React, TypeScript, Vite
- Netlify hosting, manually controlled production releases
- npm for package management

## Development

```bash
git clone https://github.com/nguyenan97/orvulix-web.git
cd orvulix-web
npm ci
npm run dev
```

## Build and test

```bash
npm run typecheck
npm run build
npm run test -- --run
```

The production build generates `public/sitemap.xml` from registered tool metadata, then builds into `dist/`.

## Search engine setup

- Production origin: https://orvulix-web.netlify.app/
- Robots: https://orvulix-web.netlify.app/robots.txt
- Sitemap: https://orvulix-web.netlify.app/sitemap.xml (available after deployment)
- Verify the URL-prefix property in Google Search Console using an HTML verification tag or HTML verification file issued for your account.
- Submit the sitemap in Search Console after production deployment. Verification credentials cannot be generated by this repository.

## Deployment

Production deployments are manual. Merge and verify CI before running a controlled Netlify deploy. Do not enable automatic deployment unless intentionally changing this release policy.
